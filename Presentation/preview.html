Target Strategy

Why group 7 classes into 4?

The original labels were detailed obesity levels. For the project goal, a simpler and clinically clearer target improves interpretability and reduces unnecessary target fragmentation.

Original target

Insufficient Weight, Normal Weight, Overweight Level I/II, Obesity Type I/II/III.

7 classes

Grouped target

Underweight, Normal, Overweight, Obesity.

4 classes
Cleaner decision level

The model predicts a broader weight status rather than fine-grained obesity stages.

Real-world logic

From obesity onward, clinical assessment or referral is generally needed.

More stable learning

Grouping reduces class fragmentation and improves evaluation stability.

Do not claim that detailed obesity stages are medically useless in general. Say they are less necessary for this model's classification goal.

Modeling Methodology

Train, validation and test were separated

The final notebook avoids choosing models on the test set. Models are compared on validation data, then the selected model is evaluated once on the reserved test set.

Validation set

Used for model comparison, final model decision, permutation importance and the Top 10 feature subset experiment.

Selection stage

Test set

Reserved for final reporting only after the final model is chosen and retrained on train + validation.

Final evaluation stage
Main metric
Macro F1

Chosen because target classes are imbalanced.

Supporting metric
Accuracy

Reported but not used alone for selection.

Diagnostic
Gap

Learning curves used to detect overfitting behavior.

The critical methodological upgrade: final test scores are not used to choose the model.

Conclusion

Final takeaways

Methodological takeaway

The project uses validation for selection and preserves the test set for final reporting, which makes the evaluation stronger academically.

Model takeaway

XGBoost is the selected final model, achieving Validation Macro F1 = 0.9139 and Test Macro F1 = 0.9080.

Feature takeaway

The Top 10 feature model gives almost the same validation Macro F1 as the full feature model.

Interpretation takeaway

BMI is a dominant label-proxy, so the model is best interpreted as BMI-assisted.

Deployment-ready idea

The selected pipeline can predict obesity class for unseen patient-like records, while the report should clearly state the role of BMI as a strong target-definition signal.
